Web Development Track

Go from your first line of HTML to a deployed website — twelve weeks of structured lessons, one practice project, a proctored-style assessment, and a certificate you can show employers.

12 weeks · Beginner · Certificate: SIDH-WD01

Checking enrollment status…

01

Learn

Five modules, each with short lessons you can complete in one sitting.

Module 1 — HTML Foundations

Document structure, semantic tags, headings, links, lists, and images. Build your first static page.

▶ Watch: HTML Full Course — freeCodeCamp
Module 2 — CSS Styling

Selectors, the box model, colors and typography, and basic responsive layout with Flexbox.

▶ Watch: CSS Full Course (Flexbox & Grid) — freeCodeCamp
Module 3 — JavaScript Basics

Variables, functions, events, and DOM manipulation — making a page respond to clicks and input.

▶ Watch: JavaScript Full Course — freeCodeCamp
Module 4 — Responsive Design

Media queries, mobile-first thinking, and testing across screen sizes.

▶ Read & watch: Responsive Design guides — freeCodeCamp
Module 5 — Deployment

Using GitHub and a free host (Netlify or GitHub Pages) to put your site live on the internet.

▶ Watch: Netlify Deployment Tutorial — freeCodeCamp
02

Practice

Build a real, deployed personal portfolio site using everything from Modules 1–5: at least three pages, responsive layout, and one working interactive element (like a contact form or a toggle menu).

Submit your live link through the contact form with subject "Program question" for informal feedback before you sit the assessment.

Ready to certify?

The assessment lives on its own page — ten questions, 70% to pass, unlimited retakes. Pass it while logged in and your certificate unlocks immediately.
